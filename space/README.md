A rule-based translator from European Portuguese to Mirandese. The rules come from the *Convenção Ortográfica da
Língua Mirandesa* (1999). The word lists come from Mirandese Wikipedia, Wiktionary and the Lhenguabase, and are
CC-BY-SA 4.0.

A native speaker corrected some words and rules. No speaker has reviewed the rest of the output. The page runs the
Python package in the browser with Pyodide.

Source code, rules, data and tests: [TigreGotico/pt2mirandese](https://github.com/TigreGotico/pt2mirandese).
